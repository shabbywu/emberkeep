Emberkeep / 烬灯地牢

Windows x64: extract the entire ZIP, then open Emberkeep/Emberkeep.exe.
macOS Apple Silicon: extract the ZIP, then open Emberkeep.app.
No Python installation, server, or network connection is required to play.

The macOS application is ad-hoc signed, without Apple Developer signing or
notarization. If macOS blocks opening a downloaded copy, use System Settings >
Privacy & Security > Open Anyway after attempting to launch it.

Save: ~/.emberkeep/save.json. Keep this directory to preserve your adventure.
Options: --cpu, --lang en, --lang zh-CN, --seed 19, --data-dir PATH.
Windows diagnostics (when no console is attached): ~/.emberkeep/emberkeep.log.
